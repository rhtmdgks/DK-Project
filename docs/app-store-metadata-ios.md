# App Store 메타데이터 (iOS) — 라온

토스처럼 **부드럽고**, **깔끔하고**, **자세하게** 썼어요. App Store Connect에 그대로 복사해 넣으시면 됩니다.

---

## 1. Promotional Text (프로모션 텍스트) — 최대 170자

앱 스토어 상단에 잠깐 보이는 문구예요. 바꿀 때마다 앱 심사 없이 반영됩니다.

```
오늘 수업, 오늘 급식, 오늘 공지까지.
대덕고등학교 생활을 한곳에서 편하게. 라온이랑 같이해요.
```

**글자 수: 52자**

---

### 대안 (원하시면 이걸로 바꿔도 돼요)

```
학교 일정부터 급식·공지까지. 찾아헤매지 않아도 되게, 한 앱에 다 모았어요. 대덕고 공식 앱 라온.
```
(58자)

## 2. Description (설명) — 최대 4,000자

아래 블록 전체를 복사해서 **설명** 칸에 붙여넣으세요.

```
학교 생활, 한곳에서

수업 시간표 확인하러 이곳저곳 들어가 보고, 급식표 찾아보고, 공지 다시 확인하고.
이제 라온 하나로 끝내면 돼요.


■ 오늘 뭐 있지? — 일정

오늘 수업부터 주간 일정까지.
한 화면에서 바로 보여드릴게요.
바쁜 아침에도 금방 확인할 수 있어요.


■ 오늘 뭐 나와? — 급식

오늘의 급식 메뉴를 앱에서 바로 확인할 수 있어요.
배고플 때 찾아헤매지 않아도 되고, 위젯으로 홈 화면에 띄워 둘 수도 있어요.


■ 공지·설문 — 놓치지 않기

공지사항이랑 설문을 한곳에서 볼 수 있어요.
참여도 앱 안에서 바로 할 수 있으니까, 링크 찾아다닐 필요 없어요.


■ 건의하기 — 말하고 싶은 거 말하기

불편한 점이 있거나, 바라는 게 있으면 건의로 보내주시면 돼요.
학생회랑 소통하는 채팅도 이용할 수 있어요.
부적절한 내용이 보이면 신고·차단 기능으로 알려줄 수 있어요.


■ 알림 — 필요한 것만 받기

일정, 급식, 공지, 날씨 알림까지.
받고 싶은 것만 골라서 설정할 수 있어요. 스팸 걱정 없이요.


■ 위젯 — 홈 화면에 올려두기

급식 출발 알림, 오늘 시간표, 이번 수업 남은 시간까지.
홈 화면에 위젯으로 올려두면 잊어버리지 않아요.

궁금한 점이 있으시면 앱 안 건의하기나 설정의 지원 메뉴를 통해 문의해 주세요. 편하게 보내주시면 돼요.
```

대덕고,대덕고등학교,학교,시간표,급식,일정,공지,설문,건의,라온,학생,공식앱

## 4. Copyright (저작권)

App Store Connect **앱 정보** 또는 **버전 정보**의 Copyright 칸에 넣을 문구예요.

```
2025 We Are Goodwill
```

또는 권리자가 학교라면:

```
2025 대덕고등학교
```

- 형식: `연도 + 공백 + 권리자 이름`
- 출시 연도에 맞춰 연도만 바꿔 주세요.

## 5. 입력할 때 체크리스트

| 항목 | 제한 | 이 문서 |
|------|------|---------|
| Promotional Text | 170자 | 52자 |
| Description | 4,000자 | 약 780자 |
| Keywords | 100자, 쉼표 구분, 공백 없음 | 48자 |

- **Promotional Text**는 나중에 심사 없이 수정 가능해요. 시즌별로 문구만 바꿔도 됩니다.
- **Keywords**에는 앱 이름(라온), 학교 이름(대덕고) 반복해서 넣지 마세요. 한 번만 넣어도 검색에 포함됩니다.

이대로 넣으시면 돼요. 수정하고 싶은 톤이나 문장 있으면 말해 주세요.

## 6. 빌드 (Build)

- **하는 일:** Xcode에서 **Product → Archive** 후 **Distribute App**으로 업로드한 빌드가 App Store Connect에 올라오면, 이 버전(1.0)에 **그 빌드를 선택**하면 됩니다.
- **채우는 법:** 업로드가 끝나고 빌드가 "처리 중"에서 "사용 가능"으로 바뀐 뒤, 이 페이지의 **빌드** 영역에서 **+** 또는 **Select a build**로 해당 빌드를 선택하세요.
- 아직 아카이브·업로드를 안 했다면 [IOS_APP_STORE_RELEASE.md](IOS_APP_STORE_RELEASE.md) 3단계를 먼저 진행하세요.

- **체크:** **하지 마세요.** LAON은 게임이 아니므로 Game Center를 사용하지 않습니다. 체크박스는 **해제** 상태로 두면 됩니다.

## 8. 앱 심사 정보 (App Review Information)

### 8.1 로그인 정보 (Sign-In Information)

LAON은 학교 계정 로그인이 필요하므로 **Sign-in required**는 **체크된 상태**로 두세요.

| 필드 | 채울 내용 |
|------|-----------|
| **User name** | 심사용 **테스트 계정 아이디**를 입력하세요. (실제 로그인 가능한 학교 계정 또는 심사 전용 테스트 계정) |
| **Password** | 해당 계정의 **비밀번호**를 입력하세요. |

- 심사팀이 이 계정으로 로그인해 앱을 확인합니다. **반드시 로그인 가능한 계정**을 넣어야 합니다.
- 심사용 전용 계정을 만든다면, 일정·급식·공지 등 주요 화면을 다 볼 수 있는 권한이 있으면 좋습니다.

---

### 8.2 연락처 정보 (Contact Information)

심사 중 문의가 있을 때 Apple이 연락할 담당자 정보입니다. **실제 연락 가능한 정보**를 넣으세요.

| 필드 | 예시 | 비고 |
|------|------|------|
| **First name** | 길동 | 담당자 이름 |
| **Last name** | 홍 | 담당자 성 |
| **Phone number** | +82 10-1234-5678 | 국가 코드 포함 권장 |
| **Email** | contact@example.com | 자주 확인하는 이메일 |

---

### 8.3 메모 (Notes)

심사팀이 앱을 이해하고 테스트하기 쉽도록 아래 문단을 **Notes** 칸에 복사해 넣어도 됩니다. (최대 4,000자) 필요하면 학교명·로그인 방식만 수정하세요.

```
LAON(라온)은 대덕고등학교 학생·교직원을 위한 공식 앱입니다. 로그인 시 위에서 입력한 테스트 계정을 사용해 주세요.

■ 로그인 후 확인 가능한 기능
- 홈: 오늘 일정, 오늘 급식, 공지 요약
- 일정: 오늘 수업·주간 일정
- 급식: 일별 급식 메뉴 (위젯도 지원)
- 공지·설문: 공지사항 목록 및 설문 참여
- 건의: 건의하기 및 학생회 채팅 (신고·차단 기능 포함)
- 알림: 푸시 알림 설정 (일정, 급식, 공지, 날씨)
- 설정: 계정 삭제, 차단한 사용자 목록, 지원/문의 정보, 개인정보 처리방침·이용약관

■ 테스트 시 참고
- 일부 메뉴는 학교 데이터(시간표, 급식, 공지)에 따라 비어 있을 수 있습니다. 로그인 후 홈과 하단 탭으로 주요 화면을 확인하시면 됩니다.
- iOS 홈 화면 위젯(급식 출발 알림, 시간표 등)은 앱 설치 후 위젯 추가 시 확인 가능합니다.

문의 사항이 있으시면 위 연락처로 연락 주세요.
```
