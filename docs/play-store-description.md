# Play Store 앱 설명 (라온)

토스처럼 **한 줄에 핵심**, **자세한 설명은 읽기 쉽게** 구성했습니다. 필요 시 복사해 Play Console에 붙여넣으세요.

---

## 간단한 설명 (80자 이내)

Play Console **앱 세부정보 → 간단한 설명**에 들어가는 문구입니다. **최대 80자**까지 입력 가능합니다.

```
학교 일정, 급식, 공지까지. 대덕고등학교를 위한 올인원 앱, 라온.
```

**글자 수: 42자** (여유 있음)

---

### 간단한 설명 대안 (선택)

- `오늘 수업, 오늘 급식, 오늘 공지. 우리 학교 앱 라온.` (28자)
- `대덕고 일정·급식·공지, 하나의 앱에서. 라온` (28자)

---

## 자세한 설명 (최대 4,000자)

Play Console **앱 세부정보 → 자세한 설명**에 들어가는 본문입니다. 아래 블록 전체를 복사해 사용하면 됩니다.

---

```
학교 생활, 한곳에서

수업 시간표 확인하러 가고, 급식표 찾아보고, 공지 다시 확인하고.
이제 라온 하나로 끝내세요.


■ 오늘 뭐 있지? — 일정

오늘 수업부터 주간 일정까지.
한 화면에서 바로 확인합니다.


■ 오늘 뭐 나와? — 급식

오늘의 급식 메뉴를 앱에서 바로 확인.
배고플 때 찾아헤매지 않아도 됩니다.


■ 공지·설문 — 놓치지 않기

공지사항과 설문을 한곳에서.
참여도 앱에서 바로 할 수 있어요.


■ 건의하기 — 말하고 싶은 거 말하기

불편한 점, 바라는 점이 있으면 건의로 보내주세요.
학생회와 소통하는 채팅도 이용할 수 있습니다.


■ 알림 — 필요한 것만 받기

일정, 급식, 공지, 날씨.
받고 싶은 알림만 골라서 설정할 수 있어요.


——————

라온은 대덕고등학교 학생과 교직원을 위한 서비스입니다.
학교 계정으로 로그인 후 이용해 주세요.

궁금한 점이 있으면 앱 내 건의하기나 문의로 연락 주시면 됩니다.
```

---

### 자세한 설명 작성 포인트 (토스 스타일)

- **첫 문장**: 한 줄로 가치 제안 (학교 생활, 한곳에서)
- **서두**: 불편함 → 해결 구조로 공감
- **섹션**: `■ 제목 — 한 줄 설명` 형태로 스캔하기 쉽게
- **문장**: 짧고 띄어쓰기 많게, 이모지 없이 깔끔하게
- **마무리**: 대상(대덕고) 명시 + 문의 유도

---

## 스크린샷/그래픽용 카피 (참고)

앱 스크린샷 위에 올릴 짧은 문구가 필요할 때:

- `오늘 수업, 여기서`
- `오늘 급식, 여기서`
- `공지·설문, 한곳에서`
- `건의하고, 소통하고`
- `알림은 내가 고른 대로`
