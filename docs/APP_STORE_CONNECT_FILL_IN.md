# App Store Connect 기입 가이드 — LAON

프로젝트 파일을 기준으로 **해당 여부**와 **기입 문구**를 정리했습니다. 필요한 곳에 복사해 넣으세요.

---

## 1. 적용 여부 요약

| 항목 | 해당 여부 | 할 일 |
|------|-----------|--------|
| **암호화(Export Compliance)** | 해당함(면제) | `ITSAppUsesNonExemptEncryption = false` 이미 Info.plist에 있음. **서류 업로드 불필요.** |
| **App Privacy(개인정보)** | 해당함 | 아래 2절대로 데이터 유형·목적 기입 |
| **Content Rights(콘텐츠 권리)** | 해당함 | 아래 3절 문구 사용 |
| **Digital Services Act** | 해당함 | Set Up 클릭 후 계정/사업자 정보 입력(화면 안내 따름) |
| **Vietnam Game License** | 해당 없음 | 게임 아님 → 기입·설정 불필요 |
| **In-App Purchase / Server Notifications** | 해당 없음 | 인앱 구매 없음 → 설정 불필요 |

## 2. App Privacy (개인정보) — 데이터 유형·목적

App Store Connect → **App Privacy**에서 “데이터 수집” 질문에 아래처럼 답하면 됩니다.

### 2.1 수집하는 데이터 유형 (선택한 것만 표시)

- **연락처 정보(Contact Info)**  
  - 이메일 주소, 이름(또는 사용자 ID)·학번 등 계정/프로필에 해당하는 항목에 체크.
- **위치(Location)**  
  - “정확한 위치” 또는 “대략적인 위치” 중 **선택 사항**인 경우에만 체크. (날씨 알림용)
- **사진·동영상(Photos or Videos)**  
  - 체크. (버그 신고 시 카메라·사진 라이브러리 첨부)
- **기타(Other)**  
  - 학번·학년·반 등 서비스 내 식별용 데이터가 “연락처”에 안 들어가면 여기서 설명.

### 2.2 “데이터 사용 목적”에 넣을 문구 (복사해서 사용)

**연락처 정보(이메일, 이름, 학번 등)**  
```
회원 가입·로그인·본인 확인, 서비스 내 신원 표시, 고객 문의 대응에 사용합니다. 회원 탈퇴 시까지 보관하며, 관련 법령이 정한 경우 해당 기간 보관합니다.
```

**위치(선택)**  
```
날씨 알림에서 현지 날씨를 보여주기 위해 사용합니다. 사용자가 동의한 경우에만 수집하며, 동의 철회 시 삭제합니다.
```

**사진**  
```
버그 신고 시 사진·스크린샷을 첨부할 때만 사용합니다. 문의 처리 목적으로만 보관합니다.
```

### 2.3 “데이터를 수집하나요?” 질문

- **예** 로 답한 뒤, 위 데이터 유형만 선택하고 각 목적은 위 문구로 채우면 됩니다.
- **광고·추적** 용도로 수집하는 데이터는 없음 → 해당 옵션은 선택하지 않습니다.  
  (프로젝트: `IS_ADS_ENABLED`·`IS_ANALYTICS_ENABLED` 모두 false, FCM은 푸시 알림만 사용.)

## 3. Content Rights(콘텐츠 권리) — 기입 문구

“Set Up Content Rights Information”에서 **저작권·상표·제3자 권리**를 물을 때 아래 중 하나를 사용하면 됩니다.

**옵션 A (간단)**  
```
본 앱(LAON)과 앱 내 텍스트·이미지·기능에 대한 저작권 및 필요한 권리는 대덕고등학교 또는 개발팀(We Are Goodwill)이 보유하며, 제3자 권리 침해가 없습니다.
```

**옵션 B (조금 더 구체적)**  
```
- 앱 이름·로고(LAON): 대덕고등학교 공식 앱으로 사용 권한을 갖고 있습니다.
- 앱 코드·디자인·콘텐츠: 대덕고등학교 또는 개발팀(We Are Goodwill)이 제작·보유하거나 사용 권한을 확보했습니다.
- 제3자 저작물(오픈소스 등)은 각 라이선스에 따라 사용하며, 앱 스토어 제출에 필요한 권리를 갖고 있습니다.
```

## 4. 암호화(Export Compliance)

- **프로젝트:** HTTPS·TLS 등 Apple OS가 제공하는 표준 암호화만 사용.  
  `ios/Runner/Info.plist`에 **`ITSAppUsesNonExemptEncryption` = `false`** 이미 설정됨.
- **할 일:** App Store Connect에서 **암호화 서류 업로드하지 않음.**  
  새로 Archive 한 빌드를 올리면 이 설정이 반영됩니다.

## 5. 기타 참고

- **개인정보 처리방침 URL**  
  `docs/privacy_policy.md` 내용을 웹에 올린 후, 그 URL을 App Store Connect “개인정보 처리방침” 칸에 입력하면 됩니다.
- **문의처**  
  App Review 정보에 넣은 연락처(이메일·전화)와 일치시키면 됩니다.

이 문서는 프로젝트 구조·Info.plist·privacy_policy·GoogleService-Info 등을 기준으로 작성했습니다. 정책이 바뀌면 App Store Connect 안내와 본 문서를 함께 확인하세요.
