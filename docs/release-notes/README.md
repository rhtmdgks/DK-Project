# 출시 노트 (Release Notes)

Play Store / App Store 업로드 시 **버전 세부정보**에 넣을 출시명·출시노트를 버전별로 관리합니다.

## 사용 방법

- 각 버전마다 `vX.Y.Z.md` 파일을 만들고, 해당 버전의 **출시명**과 **출시노트**를 작성합니다.
- Play Console 업로드 시 해당 MD 파일 내용을 복사해 **버전 세부정보** 란에 붙여넣으면 됩니다.

## 파일 규칙

| 파일 | 설명 |
|------|------|
| `v1.0.0.md` | 버전 1.0.0 (빌드 1) 출시명·출시노트 |
| `v1.0.1.md` | 버전 1.0.1 출시명·출시노트 |
| … | 필요 시 `v2.0.0.md` 등 추가 |

## 작성 형식

각 MD 파일에는 다음을 포함합니다.

- **출시명**: 스토어에 보이는 짧은 버전 제목 (예: `1.0.0 첫 출시`)
- **출시노트**: 사용자에게 보여줄 변경 사항 요약 (목록 권장)
