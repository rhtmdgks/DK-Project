## 출시노트 (Release notes)

**한국어 (기본):**

```
LAON이 처음으로 출시되었습니다.

• 일정: 오늘 수업 및 일정 확인
• 급식: 오늘의 급식 메뉴 확인
• 공지·설문: 공지사항 및 설문 참여
• 건의: 건의사항 등록 및 목록 보기
• 채팅: 건의·공지 관련 채팅
• 알림: 일정·급식·공지 등 알림 설정

불편한 점이나 건의사항은 앱 내 건의하기에서 보내 주시면 반영하겠습니다.
```

**영어 (선택, 스토어에 영어 노트가 필요할 때):**

```
LAON first release.

• Schedule: View today’s classes and schedule
• Meals: Today’s meal menu
• Notices & polls: Announcements and surveys
• Suggestions: Submit and view suggestions
• Chat: Chat for suggestions and notices
• Notifications: Settings for schedule, meals, and notices

We’ll reflect your feedback from the in-app suggestion feature.
```
