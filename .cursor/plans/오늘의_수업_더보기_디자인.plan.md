# 오늘의 수업 더보기 페이지 디자인 개편

## 목표

첨부한 레퍼런스 이미지처럼 "오늘의 수업 더보기" 화면을 다음 형태로 바꾼다.

- **다크 톤** 배경, 상단에 제목 + 프로필 아바타
- **월 + 날짜 스트립**: 선택 가능한 가로 스크롤 날짜, 선택일은 "28 THU" 형태로 강조
- **타임라인**: 왼쪽 세로선 + 상태별 원형 아이콘(완료=채움, 진행 중=채움+Now 뱃지, 예정=빈 원), 오른쪽에 과목명·강의실·선생님

---

## 현재 구조

- 화면: [lib/screens/today_classes_screen.dart](lib/screens/today_classes_screen.dart)
- 이미 구현된 것: AppBar(뒤로가기, "일정"), 연월일+Today 헤더, 요일+일자 캘린더 스트립(7일), 타임라인(세로선+원+시간+수업 카드)
- 데이터: `timetable_entries`에서 `subject`, `period`, `room`, `teacher` 로드, `_ClassItem`에 name, chapter, startTime, endTime, location, teacher 보관

---

## 변경 사항 상세

### 1. 화면 테마 및 상단

- **배경**: 이 화면만 다크 배경 적용 (예: `Color(0xFF1C1C1E)` 또는 앱 다크 서피스 색). `Scaffold(backgroundColor: ...)` 및 필요한 곳에 `Theme.of(context).copyWith(...)` 또는 로컬 텍스트/아이콘 색상으로 흰색·연회색 사용.
- **AppBar / 헤더**:
  - 왼쪽: 뒤로가기 (흰색/연회색 아이콘)
  - 중앙 또는 왼쪽: 제목 "오늘의 수업" (레퍼런스의 "Classes"에 해당, 큰 굵은 흰색)
  - 오른쪽: **프로필 아바타** (원형). `getCurrentProfile()`로 `avatarUrl` 가져와 상태에 저장 후, `resolveAvatarUrl`(또는 기존 홈 탭과 동일 방식)으로 표시. 없으면 placeholder 아이콘/이니셜.
- `_loadProfile()`에서 `avatarUrl`까지 저장하도록 수정.

### 2. 월 + 날짜 스트립

- **월 라벨**: 캘린더 스트립 위에 "3월", "MARCH" 등 (레퍼런스처럼 대문자 월 이름 가능). 선택된 날짜가 속한 월 표시.
- **날짜 스트립**:
  - 레퍼런스처럼 **가로 스크롤** 가능한 날짜 목록. (현재는 한 주 7일 고정; 선택일이 속한 주 또는 해당 월의 일부 구간으로 확장 가능.)
  - 각 셀: **일(숫자) + 요일 약어**(예: "28 THU" 또는 "28 목"). 탭 시 해당 날짜 선택 및 `_loadTimetableForDate(date)` 호출.
  - **선택된 날짜**: 배경을 약간 더 진한 블록(둥근 사각형)으로 하고, 글자 굵게 + 흰색으로 강조.
- 레이아웃: `SingleChildScrollView` + `Row` 또는 `ListView.builder`(horizontal).

### 3. 타임라인 상태(완료 / 진행 중 / 예정)

- **현재 시각 기준**으로 각 수업이 "완료 / 진행 중 / 예정"인지 구분해야 함.
- [lib/core/utils/timetable_utils.dart](lib/core/utils/timetable_utils.dart)에 **현재 교시·남은 분** 계산 유틸 추가 (다른 계획과 공유 가능):
  - 입력: `DateTime now`
  - `periodStartTimes`와 `durationMinutes`로 각 교시 시작/종료 시각 계산 후, `now`가 속한 교시가 있으면 `(period, minutesLeft)` 반환, 없으면 null.
- **선택된 날짜가 오늘인 경우에만** "진행 중" 적용. 다른 날은 모두 과거면 완료, 미래면 예정으로 단순화하거나, "오늘"일 때만 진행 중 로직 사용.
- `_ClassItem`에 `period`를 이미 포함시키고(쿼리에서 있음), 각 항목에 대해:
  - 오늘 + 현재 시각이 해당 교시 구간 안 → **진행 중**
  - 해당 교시 종료 시각 < now → **완료**
  - 해당 교시 시작 시각 > now → **예정**

### 4. 타임라인 UI

- **왼쪽**:
  - 세로선: 기존처럼 유지, 색상만 다크 테마에 맞게 (예: 연한 회색 또는 primary 강조색).
  - **원형 표시**:
    - **완료**: 채워진 원 (레퍼런스의 녹색 체크/채움에 해당, 앱에서는 primary 또는 success 색).
    - **진행 중**: 채워진 원 (동일 또는 강조색).
    - **예정**: 빈 원(테두리만).
- **시간**: "8:00 AM" 형태로 표시 (또는 기존 "09:00" 유지). 레퍼런스에 맞추려면 12시간제로 변환 가능.
- **오른쪽 행**:
  - 1줄: **과목명** + 진행 중일 때만 **"Now"** 칩(작은 둥근 뱃지, 녹색/primary). 필요 시 "N분 남음"을 Now 옆이나 아래에 추가 가능.
  - 2줄: 위치 아이콘 + 강의실(예: "Room A12" 또는 `room`이 있으면 그대로, 없으면 "-" 또는 생략).
  - 3줄: 사람 아이콘 + 선생님 이름 (`item.teacher`).
- 카드 형태보다는 **리스트 행** 스타일(배경 구분선 또는 약한 배경 블록)로 정리.

### 5. 취소(Cancelled) 상태

- 레퍼런스에는 "Cancelled" 빨간 뱃지가 있으나, 현재 DB에 취소 플래그가 없으면 **구현하지 않음**. 나중에 `timetable_entries`에 취소 필드가 생기면 같은 디자인 패턴으로 뱃지 추가 가능.

- `_ClassItem`에 `period` 필드 추가 (이미 쿼리에서 가져오므로 매핑만 추가).
- `_loadProfile()`에서 `avatarUrl` 저장.
- 아바타 표시 시 `resolveAvatarUrl` 사용 (import: `auth_repository` 또는 별도 유틸).

## 참고

- 레퍼런스는 다크 테마이므로 이 화면에서만 배경·텍스트·아이콘 색을 다크에 맞추면 된다. 앱 전역이 라이트라도 이 스크린만 다크로 가져가는 것이 목표다.
- "Now" 뱃지와 "N분 남음"은 이전 계획(메인 페이지 현재 수업 남은 시간)과 동일한 `TimetableUtils` 로직을 쓰면 된다.
